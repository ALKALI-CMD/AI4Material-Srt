# AtomLens 使用说明

这个项目研究预训练原子力场对结构变化的响应。我们使用 MACE-MP 和 CHGNet，不重新训练模型，主要考察 CsPbI3 的八面体倾斜和碘空位。

目前已经有两期较完整的实验记录，以及一组通道门控的探索结果。项目可以用于阶段汇报，但物理参照和通道机制验证还没有完成。具体结果、数据来源和未完成事项见[实验成果报告](实验成果报告.md)。

## 从哪里开始看

如果是了解项目进展，先读实验成果报告，再看其中链接的图和 JSON。第一、二期的记录分别在 `results/case1/RESULTS.md` 和 `results/case2/RESULTS.md`；第三期的状态说明在 `results/case3/RESULTS.md`。

如果要运行代码，先安装项目，再跑不依赖模型权重的测试：

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
atomlens smoke --calculator harmonic
```

真实模型实验还需要模型和绘图依赖：

```bash
python -m pip install -e ".[models,viz]"
bash scripts/run_case1.sh
bash scripts/run_case2.sh
```

这些脚本默认使用 CUDA，分别写入 `results/case1/` 和 `results/case2/`。它们会覆盖同名输出；如果要保留已有结果，请先备份或修改输出目录。脚本中的 `PY` 指向 atomlens 命令，可按自己的安装位置设置，例如 `PY="$(command -v atomlens)" bash scripts/run_case1.sh`。

已有实验的环境记录是 Python 3.12.1、PyTorch 2.5.1+cu121、mace-torch 0.3.10、CHGNet 0.4.0、ASE 3.26.0，详见 `results/case1/manifest.json`。安装新版本后得到的数值不一定完全相同。目前没有随仓库保存模型权重及其校验值，严格复现还需要补齐这一项。

## 几种分析方法分别在回答什么

### 原子能分解

两个模型都可以把总能量写成各原子能量之和。`atomlens decompose` 读取这个分解，用来比较不同局域环境，或比较同一个原子在完美结构和缺陷结构中的数值变化。

训练通常约束总能量，而不会唯一确定每个原子的能量。因此这里的原子能是模型内部的分配方式，不能直接当作可测量的单原子能量。

### 结构路径归因

`atomlens attribute` 把起点和终点之间的能量差分配到原子的位移上。计算时沿坐标路径采样力，再积分 `−力 · 位移`。各原子归因的总和应接近终点与起点的能量差；两者的差就是完备性残差，可用来检查数值积分。

本项目用立方结构和倾斜结构作为两个端点，程序在端点坐标之间做线性插值。它不是逐个角度重新生成的严格转动路径。归因结果依赖所选路径；路径上没有移动的 Cs、Pb 得到零位移归因，也不表示它们的局域环境对模型毫无作用。

### 边门控归因

`atomlens gating` 在消息传递中给原子对的消息乘一个标量门。门为 1 时保留消息，门为 0 时关闭消息。让全部门从 0 逐渐变到 1，积分能量对各门的梯度，就得到边归因。

MACE 和 CHGNet 都已实现边门控，但具体插入的位置不同。门控改变的是模型计算，不能把关闭消息理解成实际断开一根化学键。标量门本身不改变消息的旋转变换规则；已有 MACE 结果也包含旋转一致性检查。

归因之和应接近全开和全关之间的能量差。全关状态是人为的计算基线，不应未经核对就称为孤立原子能量之和。

### 差分边归因

`atomlens diff-gating` 分别计算完美结构和空位结构的边归因，把共同的周期性边对齐，再取“空位减完美”的差。这样更容易看到缺陷附近哪些消息发生了变化。

当前输出只覆盖两个结构的共同边，删除碘原子后消失的边没有作为单独的归因项输出。因此，不能把共同边差分的总和直接视为完整的缺陷形成能分解。

### 空位形成能

`atomlens formation` 使用

```text
E_form = E_vacancy − E_perfect + μ_I
μ_I = E(I2) / 2
```

计算一个固定 I2 参考下的能量差。现有晶体和分子结构没有做几何弛豫，也没有加入电荷态、温度或相稳定区间。结果适合用于比较当前模型和超胞尺寸，还不能作为经过 DFT 验证的缺陷形成能。

### 消息范数和通道分析

`atomlens channels` 记录 MACE 内部消息的数值大小；`atomlens correlation` 比较这些指标和边归因的排序。相关性说明两个量是否一起变化，不足以证明某个通道决定了能量响应。

第三期的 `channel-gating` 已有初步输出，但通道张量切片和层间门控方式还需要核查。暂时不要用它判断某一层、某个角动量通道承担了多少物理作用。

## 如何判断结果是否可靠

完备性残差用于检查归因积分是否接近目标能量差；它小，并不意味着物理解释已经得到验证。

留一消融和 top-k 忠实性实验用实际门控检查归因排序：关闭排名靠前的边，模型输出是否比随机选边变化更大。随机对照目前只有少量重复，还不能给出充分的统计置信度。

稳定性实验比较加入小幅随机位移前后的排序。现有 MACE 边归因的平均 Spearman 为 0.953，Top-10 Jaccard 为 0.646，说明总体排序相近，但前十名并非完全一致。这里的高斯位移没有对应一个确定温度。

对称性检查则比较平移、旋转、原子重编号和超胞扩展前后的模型输出。已有检查通过的范围见实验报告；没有实际运行的项目不算通过。

## 目录说明

| 目录 | 内容 |
|---|---|
| `src/atomlens/` | 结构生成、模型接口、归因和绘图代码 |
| `tests/` | 不依赖预训练权重的基础测试 |
| `scripts/` | 实验与打包脚本 |
| `results/case1/` | 路径归因、MACE 边门控、对称性和扰动检查 |
| `results/case2/` | CHGNet 门控、差分边归因、形成能和相关性分析 |
| `results/case3/` | 通道门控探索数据，尚待复核 |
| `docs/` | 使用说明、成果报告和早期研究记录 |

后续最需要补的是：统一 CHGNet 的能量口径，核查并重跑通道实验，加入弛豫结构和 DFT 参照，再扩大材料与扰动范围。HamGNN 等哈密顿模型目前还没有实现。
