# AtomLens 中文指南(通俗版)

> 这个文档解释:这个项目在做什么、每个命令怎么用、每个方法是什么意思、
> 结果应该怎么读。读完就能自己跑实验、自己讲清楚每张图。

## 一句话版本

我们拿两个现成的机器学习力场(MACE-MP 和 CHGNet),在不重新训练的前提下,
回答三个问题:

1. **模型把能量"记在"哪些原子、哪些原子对身上?**(归因)
2. **模型说的这些重要性可信吗?**(用忠实性、稳定性、对称性三类检验去验证)
3. **模型内部的数值(消息范数、角动量通道)和真实重要性是一回事吗?**(对照)

应用案例是卤化物钙钛矿 CsPbI3 的两件事:**八面体倾斜**(相变的关键畸变)
和**碘空位**(缺陷)。

## 目录里有什么

```
src/atomlens/          核心代码(每个文件一个主题)
  structures.py        造结构:立方 CsPbI3、八面体倾斜、碘空位、热扰动
  models.py            加载 MACE/CHGNet,做原子能分解
  attribution.py       方法A:结构路径积分(沿物理路径积分力)
  gating.py            方法B:边门控 + 积分梯度 + 消融对照 + 忠实性曲线(核心)
  channels.py          方法D:角动量通道(l=0,1,2,3)范数分析
  invariance.py        对称性检验:平移/旋转/重编号/超胞
  stability.py         稳定性检验:加噪声后归因排序变不变
  metrics.py           Spearman 相关、Top-k Jaccard 这些小工具
  plotting.py          所有画图
  cli.py               命令行入口(atomlens 命令)
tests/                 单元测试(python -m pytest)
scripts/run_case1.sh   一键跑完第一期全部实验
results/case1/         实验输出(JSON + PNG)
docs/                  文档
```

## 三个归因方法(通俗解释)

### 输出层:原子能分解

很多力场把总能量写成每个原子能量之和:E = E₁ + E₂ + … + Eₙ。
模型内部天然有这个数,直接读出来就行。

- **能回答**:模型把总能量主要分配给哪些局域环境;空位旁边的原子是不是
  分到了异常多的能量。
- **不能回答**:这不是"真实的单原子能量"。训练只约束总能量,
  把能量怎么摊到每个原子上有很多种分法,模型只是选了一种。
- 命令:`atomlens decompose`。

### 方法A:结构路径积分(积分梯度的物理版)

想问"这个畸变带来多少能量、是谁贡献的":让结构沿着一条**物理上有意义的
路径**从 A 变到 B(比如八面体从 0° 慢慢歪到 12°),一路上记录每个原子受到的力,
把"力 × 路程"沿路径加起来。数学上这正好把能量变化完整地分摊到每个原子头上
(残差接近 0,这是可以检验的)。

- **关键点**:路径必须是物理路径。不要用"坐标从零插值到真实结构"那种
  人造路径,中间结构没有化学意义。
- 命令:`atomlens attribute --structure-pair cspbi3_tilt`。
- MACE 和 CHGNet 都能用(只需要能量和力,不需要看模型内部)。

### 方法B:边门控(项目核心方法,MACE 和 CHGNet 都已实现)

等变模型里,"原子对之间的相互作用"就是消息传递里的**消息 m_ij**。
我们给每条边装一个 0~1 的开关 g_ij,把消息乘上 g_ij:

```
m_ij  →  g_ij · m_ij
```

- MACE 每层交互里的消息是在 `conv_tp` 模块里按边算出来的,把它的输出
  按边乘 g 就精确实现了上式,其余部分(线性层、聚合、读出)完全不动。
- CHGNet 的消息是 `MLP(...) * bond_weight`,bond_weight 按"无向键"排列,
  把 `bond_weights_ag/bg` 的输出按键乘 g,同样精确实现上式。
  (默认图参数下 CsPbI3 的角向三体图是空的,所以这覆盖了它全部消息通道。)
- g 是标量,不改变任何张量的旋转性质,**等变性保持**;
  无向原子对 (i,j) 和 (j,i) 共用一个 g,**结果不依赖边的方向定义**。
- 归因值用**积分梯度**:把开关从 0(全部关闭)慢慢开到 1(正常模型),
  一路上记录"总能量对每个开关有多敏感"(∂E/∂g),沿路加起来。
- **完备性**:所有边的归因加起来 ≈ E(门全开) − E(门全关)。
  实测残差约 0.011 eV,能量摆幅约 70 eV,相对误差 ~0.016%。
- **对照**:用"最笨但最可靠"的留一法(每次真的关掉一条边,看能量变多少)
  和积分梯度对比,两者排序的 Spearman 相关达到 0.987,说明积分梯度没骗人。
- 命令:`atomlens gating --with-ablation`。

### 差分归因:定位缺陷的正确姿势

总能量被大量等价的体相键主导(空位体系里 top 重要性边离空位甚至比随机边更远),
所以**直接看绝对归因图找不到缺陷**。正确做法是差分:

- **逐原子差分**:空位结构和完美结构的原子能逐个相减
  (命令:`python scripts/analyze_vacancy.py`)。
  实测:两个模型都把最大的信号放在"失去碘配体的 2 个 Pb"和
  "空位笼架上的 4 个 Cs"上,远处原子信号接近 0。
- **逐键差分(差分边门控)**:两个结构各跑一次边门控归因,按规范键
  对齐相减,ΔA = A(键|空位) − A(键|完美)(命令:`atomlens diff-gating`)。
  数学上等价于"对能量差做门控积分"。实测:两个模型都指认缺陷邻近的
  Pb–I 键(重要性被"卸载"),差分忠实性检验里 top-k 比随机高 10–100 倍。

### 空位形成能:让能量对比有物理口径

粗略的"按原子数缩放"会给出负的形成能(口径问题,不是物理)。
正确做法:E_form = E(空位超胞) − E(完美超胞) + μ_I,
碘富集极限取 μ_I = E(I2)/2。实测:MACE +1.05 eV、CHGNet +1.22 eV,
且 2×2×2 和 4×4×4 差距 ≤ 0.02 eV(空位互不干扰,浓度收敛)。
命令:`atomlens formation`。

### 内部指标 vs 干预指标(主论文核心问题)

"模型内部哪条边消息数值大"和"干预实验说哪条边重要"是不是一回事?
逐边算 Spearman 相关(命令:`atomlens correlation`),三个发现:

1. 消息**总范数**和干预归因的相关只有 ~0.55,还不如"键长短=重要"(~0.8):
   只看内部数值画热力图会误导;
2. 但**特定角动量通道**与干预归因高度相关:第 1 层 l2 通道(0.91–0.94)、
   第 0 层 l3 通道(0.80–0.84),超过键长对照——可解释信号集中在这些通道;
3. 这个图案跨结构、跨超胞尺寸稳定复现。

## 三类检验(方法可不可信,得靠它们)

| 检验 | 做法 | 通过标准 | 命令 |
|---|---|---|---|
| 忠实性 | 按归因排名从高到低关边,看能量变化 | top-k 曲线明显高于随机和 bottom-k | `faithfulness` |
| 稳定性 | 结构加一点热噪声(σ=0.03 Å),重新算归因 | Spearman 接近 1,Top-10 重合度高 | `stability` |
| 对称性 | 平移/旋转/原子重编号/扩超胞后重算 | 能量、力、归因排序不变 | `invariance`、`rotation_check` |

### 内部表征诊断(辅助,不能单独当重要性)

`channels` 命令记录 MACE 每层交互的**消息张量**按角动量 l 分块的
均方根范数:l=0 是标量(距离)通道,l=1 是向量(方向)通道,l=2、l=3 更精细。

- 注意:不能直接看球谐函数本身的范数——单位向量的球谐函数每个 l 块的
  范数永远是常数,不携带结构信息;要看的是"模型实际用了多少"。
- 实测发现:Pb 周围 l=3 通道活跃度是 l=0 的 5 倍(模型描述 Pb 的环境
  主要靠方向信息);八面体倾斜后各通道活跃度略降。
- 不能回答:通道活跃 ≠ 物理上重要。必须和门控结果对照着讲。

## 一键复现

```bash
bash scripts/run_case1.sh        # 全部实验 + 画图,输出在 results/case1/
python -m pytest tests/ -q       # 单元测试(不需要 GPU 和模型权重)
```

单条命令示例:

```bash
atomlens model-smoke --calculator mace-mp --structure cubic_cspbi3 --device cuda
atomlens gating --structure cspbi3_iodine_vacancy --steps 32 --with-ablation \
    --out results/case1/gating_vacancy.json
atomlens plot-edge-attribution --input results/case1/gating_vacancy.json \
    --out results/case1/gating_vacancy.png
```

## 结果怎么读(results/case1/)

| 文件 | 内容 | 关键数字 |
|---|---|---|
| `invariance_*.json` | 对称性检验 | `passed` 是否为 true |
| `tilt_series.json/png` | 能量、最大力随倾斜角变化 | 两个模型趋势是否一致 |
| `decompose_*_vacancy.*` | 空位体系的原子能分解 | 高能量原子是不是在空位旁边 |
| `gating_vacancy.*` | 边门控归因 | `completeness_residual`、`ablation_spearman` |
| `faithfulness_vacancy.*` | 忠实性曲线 | top-k 是否明显高于 random |
| `stability_*` | 稳定性 | `mean_spearman`、`mean_jaccard` |
| `channels_tilt.*` | 通道范数 vs 倾斜角 | l≥1 通道是否随倾斜增强 |
| `path_ig_*_tilt.*` | 路径积分归因 | `residual` 是否接近 0 |

## 已知边界(诚实声明)

1. CHGNet 的门控完备性残差(0.23%)比 MACE float64 差约 20 倍,
   因为 CHGNet 前向是 float32;要更干净可以给 CHGNet 转 float64。
2. 归因对象是**模型**,不是物理真实。所有结论的措辞应该是
   "模型认为……",而不是"实际上……"。
3. E0(孤立原子基准能量)和门控基线:gating 里"门全关"的能量就是
   全部 E0 之和,归因描述的是相互作用部分。
4. 门控会把模型推离训练分布(消息被削弱的结构它没见过),
   所以忠实性实验里同时跑了随机对照,单看绝对数值没有意义。
5. 形成能目前只报碘富集极限(μ_I = E_I2/2);贫瘠极限需要定义
   reservoir(比如 CsI)后再算。
6. 4×4×4 超胞的空位形成能和差分归因与 2×2×2 一致(浓度已收敛),
   更大超胞只在做表面/界面时才需要。
